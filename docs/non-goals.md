# v0.1 Non-goals

The following are intentionally outside the initial product boundary:

- built-in LLM inference
- chatbot/chat UI
- vector databases
- embedding generation
- semantic vector search
- RAG orchestration
- autonomous agents inside the server
- Redis
- PostgreSQL
- MongoDB
- Elasticsearch/OpenSearch
- Kubernetes
- microservices
- multi-node clustering
- distributed consensus
- enterprise SSO/IAM
- organization-wide multi-tenancy
- mobile applications
- complex web dashboards
- cloud-provider-specific core dependencies
- automatic semantic merge of conflicts
- hard-coded profile/memory/project/task services
- Markdown as an authoritative database

A non-goal can become future scope only through an explicit design decision and milestone update.
