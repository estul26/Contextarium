# M10 — Example Schema Packs

## Scope
Provide synthetic examples showing how domains layer on the generic core:

- profile
- memory
- knowledge
- projects
- tasks/preferences as time permits

## Non-goals
No domain pack becomes mandatory for Contextarium Core.

## Data changes
Schema definitions and synthetic sample records only.

## API changes
None beyond generic schema/record APIs.

## Security
Examples must contain synthetic data only.

## Tests
Validate sample schemas and records.

## Acceptance
At least four distinct domains operate through the same generic record engine without domain-specific core services.

## Rollback
Schema packs can be removed without changing the core engine.
